# Яндекс Метрика — четыре прототипа

1. В Яндекс Метрике создайте или используйте счётчик для `hamkuzdesign-png.github.io`.
2. В GitHub: **Settings → Secrets and variables → Actions** добавьте секрет `YM_COUNTER_ID` со значением номера счётчика.
3. В настройках счётчика включите Вебвизор и сохраните изменения. Карта кликов включается кодом автоматически.
4. В разделе **Цели** создайте восемь целей типа **Целевое событие** с идентификаторами ниже.

| Прототип | Использовал фильтры | Прошёл кратчайшим путём |
| --- | --- | --- |
| Кешбокс | `filter_used_cashbox` | `short_path_cashbox` |
| Вклад Плюс | `filter_used_deposit` | `short_path_deposit` |
| Металлы | `filter_used_metals` | `short_path_metals` |
| МТС Накопления | `filter_used_mts` | `short_path_mts` |

Что будет доступно после первой публикации с ID счётчика:

- **Карта кликов → Режим областей**: отфильтруйте URL по `prototype=cashbox`, `prototype=deposit`, `prototype=metals` или `prototype=mts`. Так можно увидеть использование фильтров на экране каталога отдельно для каждого задания.
- **Отчёты по целям**: `filter_used_*` считает уникальное использование фильтров в рамках сессии; `short_path_*` срабатывает только при открытии целевого продукта без переходов на другие продукты.
- **Карта путей**: используйте виртуальные URL с параметром `prototype`; они разделяют путь каждого задания, включая переходы «Главная → каталог → продукт → успех».
